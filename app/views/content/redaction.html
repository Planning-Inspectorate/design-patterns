Keep the user journey clear and consistent when personal or sensitive information needs to be removed.

When to use redaction

Use redaction when a user needs to hide personal, sensitive or identifying information before a document is published or shared.

The goal is to protect personal information without making the process harder than it needs to be. Redact only what is necessary and keep as much of the original content as possible.

Recommended behaviour

  • Make the user aware of what type of information needs to be removed.
  • Allow them to review the redacted content before they continue.
  • Keep the original text available if needed, but do not let it distract from the task.
  • Show the redaction clearly so the user can see what has been hidden.

If the service supports a redaction tool, use the same actions and language across the service to reduce confusion and make the process easier to complete.
