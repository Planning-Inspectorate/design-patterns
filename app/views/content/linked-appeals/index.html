Use clear and consistent names for related appeals.

Use the right names

  • Call the main appeal the lead appeal.
  • Call any associated appeals linked appeals.

Do not use the term child appeal for these related cases. The linked appeal language is clearer and helps users understand the relationship without implying a hierarchy.

This language should be used consistently across case summaries, appeal lists and internal guidance so users can easily understand how the appeals are connected.
