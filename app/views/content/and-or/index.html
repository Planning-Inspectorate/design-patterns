Avoid using and/or in user-facing content.

Symbols such as ampersands, slashes and dashes can be harder for users to read at a glance. Write the option in plain English.

Use plain wording instead

  • Use or when either option is acceptable.
  • Use and when both options are needed.
  • Use or both when the user may choose either option or both together.

For example, write Thing or other thing rather than thing/other thing. If both are possible, write Thing or other thing (or both).

This makes the choice easier to scan and reduces the chance that users misread the instructions.
