Talking about the use of AI in written representations

Use the following wording to tell users how they can use AI in a written representation:

You can use artificial intelligence (AI) tools to help draft or translate your written representation. You must check that everything is accurate and reflects your own views.

Question page

This page asks the user whether they used AI when preparing their written representation. It tells Inspectors how the representation was prepared.

{{ embed("ai-question", "Question page", "ai-declaration/question.html", "760px", questionCode) }}

What it covers

The page tells users that we ask about AI used to:

  • write the representation
  • translate the representation
  • generate images or other attachments

What it does not cover

Users do not need to tell us if they used AI to check spelling or grammar. Keep this line on the page so users do not declare minor tool use.

How to use it

  • Use the same wording, bullets and Yes or No options in every service.
  • Do not mark the question as optional. Users must answer it to continue.
  • If the user answers Yes, show the next page asking how they used AI.
  • If the user answers No, skip the next page and go to the declaration.

How AI was used

This page asks users to explain how they used AI in their written representation. It gives Inspectors more detail about how the representation was prepared.

{{ embed("ai-how", "How AI was used", "ai-declaration/how.html", "420px", howCode) }}

When to show it

Only show this page if the user answered Yes on the question page.

How to use it

  • Use a text area so users can describe their AI use in their own words.
  • Keep the hint, which gives examples such as drafting or translating.
  • Ask the question as the page heading, so the label is the heading.

Declaration

The declaration confirms that the user has checked any AI-generated content in their representation. It reminds users that the representation must reflect their own views.

The AI declaration is a checkbox. It appears with the other declarations the user must confirm before they submit their representation, not on a page of its own.

{{ embed("ai-declaration", "Declaration", "ai-declaration/declaration.html", "240px", declarationCode) }}

How to use it

  • Use the same wording in every service.
  • Add it as another checkbox in the same group as the service's other declarations.
  • Show it to all users, including those who answered No on the question page.
  • Show it as part of the final declaration, before the user submits their representation.

User research

Research with public and professional users found that strong declarations about AI-generated content could feel unreasonable or threatening. Some users did not feel able to guarantee that information generated using AI was completely accurate.

Users also questioned why they needed to tell us about their use of AI and whether declaring AI use could affect how their representation was treated.

What we learned

The research supports:

  • explaining why we ask about AI use
  • focusing the declaration on users checking the content rather than guaranteeing its accuracy
  • making clear that the representation must reflect the user's own views
  • avoiding language that suggests using AI makes a representation less valid
  • allowing people to use tools that help them draft their response without making them feel their participation could be devalued
