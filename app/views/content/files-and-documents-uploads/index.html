Use the right terms for the thing the user is dealing with.

Use document for content

Use document when you mean the content or item being reviewed, uploaded or attached.

Use file for the technical format

Use file only when you mean the downloadable technical format, such as a PDF, Word document or other digital file.

Choose the right action word

  • Manage when a user can do more than one thing to a document or file, such as change its name, amend the details, share it, redact it or replace it.
  • Change when you are only changing one thing about a file or document.
  • Edit when you are changing the contents of a file or document.
  • View when a user wants to look at a file, document or email without making changes.
  • Add when a user is adding another file or document in the back office, or where multiple files are allowed in the front office.
  • Upload when the user is adding files or documents in the front office and the service only allows a single file upload at that point.

This keeps language consistent and helps users understand whether they are editing the content, managing the record, or uploading a file.
