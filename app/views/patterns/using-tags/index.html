Use coloured tags to help users see the status of an item or task.

Recommended rules for consistent tag colour usage across Planning Inspectorate services, based on existing design system guidance, current practice, and a small number of additional recommendations.

When to use tags

Use a tag when users need to quickly identify the status of something.

For example:

  • a task is in progress
  • a document is awaiting review
  • an appeal has been allowed
  • an item requires urgent attention

Do not use tags simply to decorate or categorise content.

Do not rely on colour alone

The text inside a tag must clearly communicate its meaning without relying on the user being able to perceive its colour.

Use short, consistent labels written in sentence case, such as:

  • In progress
  • Not started yet
  • Awaiting review
  • Current version

Five colour tag system

Use one of the five standard colours wherever possible.

“Be consistent, not uniform.” — Government Design Principles and Being consistent, not uniform

Services may need different labels to describe their processes.

Blue: active

Active, in-progress activity, or contextual document indicators.

{{ govukTag({ text: "Current version", classes: "govuk-tag--blue" }) }}

Use a blue tag for:

  • an in progress task
  • incomplete work
  • current version
  • shared
  • unread
  • transferred

Do not use blue when the current user cannot take action.

Grey: inactive

Use a grey tag when something is inactive, unavailable or has not started.

{{ govukTag({ text: "Withdrawn", classes: "govuk-tag--grey" }) }}

Use a grey tag for:

  • Not started yet
  • Cannot start yet
  • Closed
  • Withdrawn
  • Draft, where inactive
  • Not published

Do not use grey for urgent issues or positive outcomes.

Green: positive

Use a green tag for successful completion, availability or a positive outcome.

{{ govukTag({ text: "Published", classes: "govuk-tag--green" }) }}

Use a green tag for:

  • Completed tasks
  • Accepted outcomes
  • Allowed appeals
  • Published states
  • Paid items
  • Read items

Do not use green for neutral waiting states or blocked work.

Yellow: awaiting

Use a yellow tag when something is waiting, pending, paused or dependent on another action.

{{ govukTag({ text: "Awaiting review", classes: "govuk-tag--yellow" }) }}

Use a yellow tag for:

  • Awaiting review
  • Awaiting site visit
  • Awaiting hearing
  • Awaiting inquiry
  • Scanning for viruses

Do not use yellow for successful completion or urgent failures.

Red: warning

Use a red tag when something is late, blocked, invalid or requires urgent attention.

{{ govukTag({ text: "Rejected", classes: "govuk-tag--red" }) }}

Use a red tag for:

  • Overdue
  • Invalid
  • Rejected
  • Flagged
  • Virus detected
  • Content warning

Do not use red for routine inactive states.

Using other colours

Only use secondary colours when you need to distinguish between stages in a complex specialist workflow.

{{ govukTag({ text: "Automated", classes: "govuk-tag--purple" }) }}

Check your tag

Before adding a tag, check that:

  • the text clearly communicates the status
  • the meaning does not depend on colour
  • the label is short and written in sentence case
  • the colour has the same meaning elsewhere in the service
  • tags are used consistently across the service
