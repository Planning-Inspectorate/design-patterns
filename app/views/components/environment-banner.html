In use

Use an environment banner to show users whether they're in a test or live environment.

The environment banner can be shown using a variable so that people can see the difference between environmants, such as test or training.

When to use this component

Use the environment banner when you need to differenciate between deployed environments.

How to use this component

Differentiate between environments using the text and colours.

If the banner variable is set to 'test', the test version of the banner will show. If the banner variable is set to anything else, the other version of the banner will show.

When not to use this component

This banner is not intended to be used for public facing websites. It is intended to be used for internal services only.

How it works

When a variable is set the banner appears at the top of the page. It has a ‘Test’ and ‘Training’ variants, these could be extended to other versions.
